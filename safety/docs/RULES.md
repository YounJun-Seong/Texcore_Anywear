# 안전 규칙 검토서 (의료 자문단용) — 규칙 0.1.0-draft

이 문서는 `rules/safety_rules.yaml`을 사람이 읽는 표로 옮긴 것이다. 수치는 계획서 5장 초안이며
**자문단 확정 전에는 출시 불가**다. 판정은 100% 규칙 기반이고 생성형 AI는 관여하지 않는다.

검토 방법: `scenarios/` 폴더를 복사해 `expected` 열을 자문단 판단으로 고친 뒤
`python tools/agreement_report.py --answers <폴더>` 를 돌리면 엔진과의 일치율(기준 98%)과 불일치 목록이 나온다.

## 2. 사용 전 하드 게이트 (5-1)
의사 확인서 없으면 운동 기능 잠금: 불안정 협심증, 조절 안 되는 부정맥, 악화 중인 심부전, 최근 심근경색·심장 수술·뇌졸중,
중증 대동맥판 협착, 실신 병력, 문진(PAR-Q+ 간소화) 위험 응답.
심박조율기·ICD는 확인서가 있어도 **의사가 정한 운동 심박 상한**이 입력돼야 열린다.

## 3. 운동 전 신호등 (5-2)
판정 순서: ① 급성 위급 증상 → 119 ② 하드 게이트 → 잠금 ③ 나머지 항목 중 **가장 나쁜 것**.
우선순위: 119 > 잠금 > 빨강 > 재측정 > 노랑 > 초록

| 항목 | 초록 | 노랑 | 빨강 |
|---|---|---|---|
| 수축기 | 90~159 | 160~179 | ≥180 또는 <90 |
| 이완기 | 50~99 | 100~109 | ≥110 또는 <50 |
| 안정 시 심박 | 50~99 | 45~49, 100~119 | ≥120 또는 <45 |
| 증상 | 없음 | 가벼운 피로 | 숨참, 어지러움·실신감, 심한 피로 |
| 컨디션 | 정상 | 3일 이상 쉼, 수면 부족, 약 누락 | 열, 감기·설사 등 급성 질환 |

- 119: 흉통, 실신, 의식 저하, 한쪽 팔다리 마비, 말 어눌함
- 혈압은 상완형만 인정(수동 입력·BLE). 워치 혈압은 재측정 안내.
- 의사 개인 한도(수축기·이완기·심박 상한)는 기본 빨강 기준보다 **낮을 때만** 적용, 넘으면 빨강. 더 느슨한 값은 무시하고 로그에 남김.

## 4. 운동 중 (5-3)
- 최대심박 = 208 − 0.7 × 나이 (Tanaka). 상한 = 시작 4주 70%, 4주 후 + 승급 승인 시 76%, 어떤 경우에도 85% 이하. 소수점은 내림.
- 노랑 날은 64% 상한. 의사 상한이 더 낮으면 의사 값.
- 베타차단제: 구간 안내 끔. 85% 상한은 이상 감지용으로만 유지, RPE·대화 테스트 중심.

| 상황 | 반응 |
|---|---|
| 상한을 30초 **넘게** 초과 | 천천히(강도 한 단계 낮춤) |
| 그 뒤 120초 안에 상한 아래로 못 돌아옴 | 일시정지, 재개 여부 질문 |
| 상한 × 1.10 이상 | 즉시 중단 (워치=B 등급은 일시정지까지만) |
| 10초 안에 30bpm 이상 변화 | 즉시 중단 (B 등급은 일시정지) |
| RPE 14~15 / 16 이상 | 한 단계 낮춤 / 중단 |
| 숨참·어지러움·식은땀·시야 이상 | 중단 → "괜찮으세요?" |
| 흉통·실신·의식 저하·한쪽 마비·말 어눌함 | 중단 → 119 화면 |
| "그만" 버튼 | 중단 → "괜찮으세요?" |
| 3분마다 | "숨이 차세요? 말은 하실 수 있나요?" |
| 3분 무응답 | 보호자 알림 + 큰 소리 (일시정지 중에도) |
| 심박 15초 넘게 끊김·비현실 값 | 강도 한 단계 낮춤, 확인 질문 60초마다 |
| 운동 후 3분 휴식 심박 ≥ 안정 시 + 20 | 다음 운동 강도 한 단계 낮춤 |

## 5. 응급 흐름 (5-4)
- 중단 → 앉아서 쉬기 안내 → "괜찮으세요?"(괜찮아요/아니에요) → 아니에요 또는 60초 무응답 → 보호자(전화 우선 + 푸시)
- 심한 증상 → 119 화면, 발신은 1탭 확인 → 발신 시 보호자에게도 알림 / 30초 무응답 → 보호자에게 119 연결 요청
- 시간 초과로 보호자에게 알림이 간 뒤 "괜찮아요"를 눌러도 알림을 취소하지 않음
