# 어르신용 앱 (Flutter)

화면 12개(계획서 4장): 시작·본인인증 / 기본 정보·질환 / 운동 전 문진 / 오늘의 운동 / 운동 전 점검 / 신호등 결과 /
운동 진행 / 숨찬 정도 질문 / 중단·응급 / 완료·칭찬 / 이번 주 기록 / 보호자 연결.

- **안전 판정은 단말에서**: `../safety_dart` 엔진을 내장. 운동 전 점검은 단말과 서버가 각각 판정하고 **더 나쁜 쪽**을 따른다.
  운동 중 심박·숨찬 정도·증상·무응답 판정과 응급 흐름(괜찮으세요? → 보호자 / 119)은 인터넷 없이도 동작한다.
- **고령자 UX**: 본문 20sp, 숫자 44sp 이상, 버튼 높이 64dp, 화면마다 하단 주 버튼 1개, "뒤로"는 글자로 항상 표시,
  스와이프·길게 누르기·햄버거 메뉴 없음, 신호등은 색+아이콘+글자, 글자 크기 3단계, 다크모드, 안내 음성 기본 켜짐.
- 운동 시작은 서버 연결이 필요하다(서버가 오늘 판정을 다시 확인하고 기록을 연다).

## 실행
```bash
flutter pub get
flutter test                                   # 화면 흐름·응급·오프라인·접근성 검사(가짜 서버)
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000 --dart-define=ALLOW_DRAFT_RULES=true
```
실제 서버와 계약 테스트(앱이 읽는 응답 키가 서버에 있는지):
```bash
SMS_FILE=/tmp/sms.txt python ../server/tests/e2e_server.py 8766 &
E2E_SERVER=http://127.0.0.1:8766 SMS_FILE=/tmp/sms.txt flutter test test/server_contract_test.dart
```
